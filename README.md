# Koode · കൂടെ — website

The landing page for [Koode](https://github.com/AravindRKrishnan7/Koode), a Malayalam-first AI companion for Chrome.
**The web speaks your language.**

A static, dependency-free site: `index.html`, `styles.css`, `main.js` and `assets/`. No build step.

- **Preview locally:** `python3 -m http.server 8899`, then open http://127.0.0.1:8899
- **Vercel:** import this repository with Root Directory `./` and Application Preset **Other**
  (no build command; output is the repository root).

Screenshots in `assets/` are genuine captures from Koode's automated test runs (labelled test planner); the Sarathi
image is the live public portal, logged out. Fonts load from Google Fonts; nothing else is fetched or tracked.
